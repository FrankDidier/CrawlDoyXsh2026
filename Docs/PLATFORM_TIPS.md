# 各平台使用说明（必读）

受各站风控影响，**没有**“四个平台全自动零操作”的保证。请按下面方式操作，**优先保证淘宝/京东电商场景**。

## 通用

1. 使用 **本机已安装的 Chrome**，先在本机 Chrome 里登录一次淘宝/京东（如需要）。
2. 程序会打开**独立配置目录**的浏览器窗口，与日常 Chrome **不是同一套 Cookie**。请在**程序弹出的窗口里**完成登录、验证码。
3. 出现 **#go** 提示时：在地址栏**末尾**输入 `#go` 再回车，可立即开始抓取；不加则会**自动倒计时**后继续。
4. **抖音 / 快手** 网页搜索常要求登录或人机验证，若结果为 0：换关键词、或用手机 App 分享链接到剪贴板（若程序支持解析）。

## 淘宝（推荐优先测）

- 选 **店铺**：已使用店铺搜索参数 `tab=shop`。
- 若仍被拦截：在弹出窗口内完成滑块 → 刷新 → 再点抓取。
- 商品与店铺请**分别**搜索，关键词尽量具体。

## 京东

- 若跳转到登录页：先在弹出窗口登录再搜索。
- 搜索页加载后设好筛选，再加 `#go` 或等自动开始。

## 抖音 / 快手

- 必须先能在浏览器里**看到搜索结果列表**再抓取。
- 程序会多滚屏、多匹配链接格式；若仍为空，多为**未登录**或**搜索页被风控**，不是提取代码单点问题。

## 建议组合（“两个好用”）

- **淘宝 + 京东**：同一类电商需求，在弹出浏览器内登录后成功率最高。
- **抖音或快手**：适合已能正常打开搜索页的环境；否则请先解决登录与网络。
